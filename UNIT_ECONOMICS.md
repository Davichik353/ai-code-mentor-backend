# Себестоимость и цена на ученика

**Измеренной себестоимости пока нет.** Запрос 70 млн сум — бюджет развития, а не цена подписки и не расход на API. Бесплатный лимит Gemini может дать нулевой счёт сегодня, но не является гарантией бесплатного масштабирования.

## Что измеряет приложение

Таблица `ai_usage`: модель, входные и выходные токены, общие токены, время и исход каждого обращения к провайдеру. Учитываются fallback, невалидный JSON и ошибки; отсутствующая usage metadata записывается как неизвестная, а не нулевая. Выход включает reasoning-токены, если они отражены в общем количестве. Учёт не сохраняет промпты и ответы. Суточный лимит по умолчанию: 20 анализов на пользователя и 200 на сервис; один анализ может обратиться к нескольким моделям.

Внутренний кэш статистики не является кэшем Gemini-анализа. Не заявляйте экономию на анализах, пока она не реализована и не измерена.

## Расчёт

Для каждой модели: `API USD = input_tokens / 1e6 × input_rate + output_tokens / 1e6 × output_rate`.

`Себестоимость ученика за период = (API USD × курс USD/UZS + инфраструктура + поддержка) / активные ученики`.

`Цена для целевой валовой маржи = себестоимость / (1 − маржа)`.

Отдельно учитывать налоги, комиссии, привлечение и разработку при расчёте прибыли. Периоды расходов и активности должны совпадать. Бесплатные квоты/кредиты и оплачиваемую цену моделировать отдельными сценариями. Кэшированные входные токены здесь консервативно считаются по полной входной цене.

## Команда

Скопируйте `pricing.example.json` вне Git и заполните актуальные цены **для моделей и тарифа вашего аккаунта** по https://ai.google.dev/gemini-api/docs/pricing . Запишите дату и источник. Не переносите цены другой модели по похожему названию.

```bash
python scripts/cost_report.py --prices /private/prices.json \
  --start 2026-11-01 --end 2026-12-01 --learners 20 \
  --usd-uzs 12000 --fixed-uzs 500000 --margin 0.5
```

Все значения в примере — иллюстрация вызова, **не бизнес-прогноз и не текущий курс**. Введите фактический курс и расходы за тот же период. При неизвестных ценах или токенах итоговая цена остаётся `null`. При отсутствии измерений подписка этим отчётом не обосновывается.
