# Учебный каталог: темы и происхождение

Каталог содержит 18 тем с реализациями на Python и JavaScript — 36 упражнений.
Категории: ввод и вычисления, условия, циклы, строки, списки, логика. Уровни:
«Новичок» и «Продолжающий». Для каждого задания предусмотрены русская и узбекская
(латиница) версии, последовательные подсказки, проверочные примеры, образцовое
решение и дополнительное условие для мини-защиты.

Пользователь предложил https://pythontutor.ru/old/ как ориентир. Разделы старого
учебника просмотрены 8 ноября 2026 года: ввод/вывод, условия, вычисления, циклы,
строки, списки и следующие темы. Это полезный ориентир по последовательности
изучения. На сайте авторами исходных материалов названы Д. П. Кириенко и команда
Pythontutor; AI Code Mentor не заявляет авторство их курса или партнёрство с ними.

В проект не импортированы страницы учебника, его тестовый набор или готовые
решения. Новые условия, переводы, подсказки, примеры и программные решения
составлены отдельно на общие вводные темы программирования. Общие математические
задачи (чётность, високосный год, факториал, неравенство треугольника) не являются
заявлением об уникальности учебной методики.

Python-решения прогоняются на всех опубликованных примерах через subprocess с
тайм-аутом в `tests/test_learning_catalog.py`. Оба языка также проверяются
браузерным исполнителем в frontend `tests/exercise-runtime.cjs`. Эти примеры
проверяют отдельные случаи, а не доказывают правильность любого ученического
решения: окончательную оценку понимания выполняет преподаватель по мини-защите.
